# Modules

- `auth`: OTP verification, JWT issuance, subscription timer start.
- `users`: Admin/candidate profiles and roles.
- `subscriptions`: Plan tiers, purchase records, expiry logic.
- `tests`: Listening/Reading engine, question banks.
- `tasks`: 40-day daily task builder and assignments.
- `grading`: N.A.S.I.R. Protocol™ scoring and band mapping.
- `blogs`: Public content management.
