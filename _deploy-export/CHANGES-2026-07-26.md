- **Exam player** — Part A 15-min + Parts B&C 45-min shared timer; screenshot security (3 strikes → login suspension; admin reinstate).
- **Dynamic pricing & upgrades** — admin-editable plan/product prices & limits; grant/revoke a user's courses; upgrade-pays-difference; Stripe checkout for Complete plans.
- **Cohort + study plan** — single "Cohort Live Lectures" page; cohort session cards embedded in 40-day study-plan.

- **Candidate portal redesign** — premium dashboard, progress, lectures, course tests, past papers, skill practice.
- **Skill drills** — admin HTML drill library; portal daily-rotating Part A "drill of the day" (sandboxed iframe).
- **Spelling** — DB-backed 1,938-term bank + admin; portal TTS engine.
- **Reading articles** — admin bulk-paste bank; daily global rotation; premium reader.
- **Listening podcasts** — admin audio upload (file+URL); daily rotation; player + per-student listen tracking.
- **Profession / source** — required at signup; colour-coded + filterable in admin users; homepage "Included free" strips.
- **Accountability** — admin daily dashboard (lecture/test/spelling/podcast/article ticks) + warning emails (single + bulk).
- **Writing course** — per-profession case-note libraries; premium 45-min writing exam; submission → per-profession correction email; per-student writing ID + letter history.
